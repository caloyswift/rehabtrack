# RehabTrack — Codex Instructions

## Project Overview
RehabTrack is a web-based stroke rehabilitation monitoring system built with HTML, CSS, and JavaScript.

## Project Structure
- `index.html` — landing page
- `login.html` — login page
- `patient.html` — patient dashboard
- `therapist.html` — therapist dashboard
- `css/` — stylesheets
- `js/` — JavaScript functionality
- `assets/` — images and other assets

## Development Rules
- Use plain HTML, CSS, and JavaScript.
- Do not introduce frameworks or libraries unless explicitly requested.
- Keep the existing project structure.
- Do not delete or overwrite existing functionality unnecessarily.
- Make the smallest changes necessary to complete a task.
- Keep the UI consistent with the existing design.
- Before changing code, inspect the relevant files first.

## Testing
After making changes:
- Check for JavaScript syntax errors.
- Check that HTML references to CSS and JavaScript files remain valid.
- Do not modify unrelated files.
